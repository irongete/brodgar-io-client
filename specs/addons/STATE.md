## Read API (`hafen.*`), UI (`hafen.ui`), hooks, input
- **Gobs (OOP, D-044/045)**: `hafen.gob(id)` → an interned Gob (`:pos/name/health/facing/moving/speed/speech/icon/overlays/isplayer/distance/exists/id/info`); the flat `gob.*(ref)` table and the `"player"`/`"partyN"` tokens are GONE. `world.*` hands out Gobs. **Kin (OOP, D-056)**: `hafen.kin` is CALLABLE-ONLY — `hafen.kin()` = the roster of interned Kin (+`:find/:list/:add`), `hafen.kin(idOrName)` = one Kin (`:id/:name/:group/:color/:online/:exists/:info`; gated `:rename/:setGroup(0..254)/:endkin/:forget` chain on self); `KinChanged` = a per-addon `Kin[]`. **Kin ↔ Gob**: `gob:kin()` = the `ui/obj/buddy` attrib, `kin:gob()` = an `OCache` sweep **preferring the body**. **Actionbar (OOP, D-057)**: CALLABLE-ONLY — `hafen.actionbar(n)` = the Slot at the raw 0-based game index (0..143), `hafen.actionbar()` = the **1-based** array of all 144; `slot:index/:empty/:res/:name/:cooldown/:info` + gated `:use([mods])`/`:set(res)` (ASYNC — the server echoes it back). **Map** `map.*`: tile/height/grid/gridPos + conversions, grid ids = exact decimal strings. **Meters (OOP)**: `hafen.meter()` = every HUD bar (1-based, HUD order) / `hafen.meter(needle)` = the first whose server-published `IMeter.bg` name contains it; `MeterAdded`/`MeterRemoved`/`MeterChanged` carry the Meter. **Player/char**: `hafen.player()` → Player object (`:gob()/:name()/:worldToScreen()`, D-046); `char.*` (attrs/food/skills/lp/weight), `time/party/buffs/study.*`. **`hafen.items` is GONE (029.3)** — items are `widget:items()`. **Gap subsystems** (A1–A11) `markers/radar/kin/speed/craft/quests/wounds/fight` — widget-tree adapters. Overlays `ui.overlay`/`ui.gobOverlay`; `LuaGOut` draw wrapper.
- **Client options** `hafen.client:options()` → `interface/video/audio/camera/client/keybindings`, one per OptWnd panel over the stores OptWnd writes; arity is the verb (`opt:name()` reads, `opt:name(v)` writes + chains). `keybindings` = `register(name, fn)` (UNBOUND, D-047) + `get/set/list/unregister`; `hafen.key` GONE; slash `hafen.slash.register`.
- **Profiling** (019): Options ▸ **Client** ▸ "Enable profiling" = ONE switch (D-049), next-frame. `hafen.client:profiling()` → `:frame()`/`:history(n)`/`:reset()`; absent key = not measured, off ⇒ `{}` (D-050). **Pull-only counters** `:memory/:net/:loader/:render/:textcache` (D-051) answer **off**; `:addons()`+`:scope`/ `:measure` = the D-018 watchdog's OWN measurement (D-052); `:widgets()` = ONE `// addon:` `long[] prof` on `Widget` (D-053); `:passes()` = FIXED `shadow`/`scene`/`ui2d`, CPU+GPU (D-054; `:gl()` = ARMED-ONLY); `:overhead()` = five tiers, **0.54% of frame** (D-055).

## Actions (gated write tier), virtual entities, rendering, data, fonts, example addons
- `hafen.act.*`: moveTo/clickGob(gob)/useItemOn/place/select/raw, menu/flower, item verbs + per-subsystem verbs (`slot:use`/`:set`, speed.set, `kin:rename/…`, craft.make…; **`pag:use()`** ungated).
