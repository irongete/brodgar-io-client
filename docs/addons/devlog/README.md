- [r2b-billboard-sprite](r2b-billboard-sprite.md) — `hafen.render.sprite{…,billboard=true}` stands the PNG as a **camera-facing** screen blit — the second visual on the shared R2a core: a resource-free **`LuaSpriteBillboard extends Drawable implements PView.Render2D`** (the `SpeakerIcon`/`LuaGobOverlay` pattern) whose `draw` projects the gob origin (`Homo3D.obj2view`) and blits the `TexI` bottom-centred, reading the `GhostGob`'s live alpha/tint/scale (it's a `Drawable`, so the gob keeps a Drawable → dodges `Gob.ctick`'s empty-virtual-gob cleanup, and `Gob.added` registers its `Render2D` in the 2D pass). - [r3a-models-world](r3a-models-world.md) — `hafen.render.model(path)` loads an addon's own **glTF 2.0 static model** (`.glb`/`.gltf`) via a **pure-Java parser** (new **`Gltf`** over our `Json`, no native deps) into a cached, bridge-owned mesh handle (`:bounds()`/`:dispose()`), and `hafen.render.object{model,x,y[,a,scale,alpha,tint,clickable,follow]}` stands it in the 3D world — the **mesh** sibling of a sprite/ghost on the same world-entity core + gizmo. The parser reads the `.glb` header/chunks + `.gltf` data-URI/external buffers, decodes accessors (6 componentTypes, stride, normalization) + indices, **bakes node transforms** down the tree, and applies a **basis conversion** (glTF +Y-up metres → H&H +Z-up, **1 metre = 1 tile**, a det-+1 rotation × unit scale) so geometry comes out H&H-local; caps (prims/verts/bytes) + named errors for unsupported features (D-018). New **`MeshSprite`** builds one `POSITION`-only `Homo3D.vertex` `Model` + a flat **`BaseColor`** (`baseColorFactor`) unlit `Material` per primitive (`nofacecull` double-sided); new **`LuaObject extends LuaWorldEntity`** + **`LuaMesh`** asset handle; V2 pick generalized to objects (**`ObjectClicked`**). **Zero `haven` core edit** (reuses the V1 `addClientGob` + V2 `Click.hit` seams; render primitives + `Matrix4f` all public); **27 headless parser checks**; `hello` v0.42.0 ships `cube.glb` + `:hello object` (stands + live-transforms a glTF cube). Static + **unlit** (textures → R3b, lighting → R3c)
- [r3b1-textures-materials](r3b1-textures-materials.md) — makes glTF models render **textured, multi-material** (the maintainer's `tank.glb` — 53 prims, 4 embedded PNGs — goes from a grey blob to a textured tank). `Gltf` now decodes **`TEXCOORD_0`** + the full material (`baseColorTexture`, `alphaMode` OPAQUE/MASK/BLEND, `alphaCutoff`, `doubleSided`) and **extracts each referenced image to a raw byte blob** — from a `bufferView`, a `data:` URI, or an external file — **lazy + deduped** (53 materials → **4** images), staying pure (no GL/`ImageIO`, still headless-testable). `newMesh` decodes the blobs to **shared `TexI`s** the **`LuaMesh` owns** (`new TexI(img,false)` — no POT rounding, so `[0,1]` UVs sample correctly; freed in `disposeMesh`, teardown-ordered after objects). **`MeshSprite`** builds a `POSITION`+`TEXCOORD_0` interleaved `Model` + a per-material `Material` — **`TexDraw` × `BaseColor`** (`baseColorTexture` × `baseColorFactor`), `MASK`→`TexClip` / `BLEND`→`FragColor.blend`+`maskdepth`, `doubleSided`→`nofacecull` else back-face `Facecull`. Still **unlit** (lighting → R3c). New mesh-handle **`:info()`** (`{prims,textured,textures,verts,tris}`); `mesh:dispose()` now frees textures too. **Zero `haven` core edit** (all texture/material primitives public); **43 headless parser checks** (real `tank.glb` + synthetic data-URI/external/untextured/error/basis); `hello` v0.43.0 (`:hello object` stands the tank textured, scaled from `:bounds()`). *(R3b-1 of 2 — R3b-2 = `planner` integration. UV `v`-flip is the one in-game unknown: `MeshSprite.TEXV_FLIP`.)*
- [r3b2-planner-object](r3b2-planner-object.md) — wires glTF models into the **`planner`** editor (the object analog of what R2b did for sprites): a `kind="object"` record + **`:planner object`** stands a shipped **`cube.glb`** at your feet, **click-selectable** (its mesh is in the clickmap → the click fires the per-object `onClick` + the owner-scoped **`ObjectClicked`**), **gizmo-driven** (move/rotate/scale — the same handle `:hello object` proves), and **grid-anchor-persisted** (a `model` path stored beside `res`/`img`; re-resolved via `hafen.map.gridPos`/`fromGridPos` on relog). **Lua-only** — the object render, transform handle, V2 pick, and gizmo-compatibility all shipped in R3a/R3b-1, so this touches **only `addons/planner/`** (no `haven` core edit, no `io.brodgar.addon` change). LuaJ-parse verified; `planner` v0.6.0. **Completes R3b**
- [r3c-lighting](r3c-lighting.md) — makes glTF models **shade with the world lights** instead of drawing fullbright (the R-series finale). `Gltf` bakes per-vertex **`NORMAL`s** — from the glTF attribute, transformed by the **inverse-transpose** of the `basis·node` matrix (so non-uniform node scale shears them correctly), or **computed smooth** (area-weighted face normals) when the mesh has none — plus **`emissiveFactor`**, both baked H&H-local, staying pure/headless-testable. **`MeshSprite.buildModel`** is now a generic interleaver (`POSITION` + `NORMAL` when lit + `TEXCOORD_0` when textured → stride 12/20/24/32) feeding `Homo3D.normal`, and each lit material adds a **`Light.PhongLight`** state so the engine's `Phong` shader multiplies the MapView scene's world lights into the fragment (albedo = R3b's texture × `baseColorFactor`; `emissiveFactor`→`emi`; neutral matte reflectance, per-fragment). New `:info().lit` count. **sRGB is a deliberate no-op** — the engine never `.srgb()`s model textures, so our `UNORM8` `TexI`s already match world geometry. **Zero `haven` core edit** (reuses the V1 `addClientGob` + R3b material path; `Homo3D.normal`/`Light.PhongLight` public); **10 headless parser checks** (synthetic with/without-NORMAL triangles agree on `(0,-1,0)` + emissive + unit-length; real `tank.glb` all-lit) + LuaJ parse; `hello` v0.44.0 (`:hello object` now stands the tank **lit**). **Completes R3 + the whole R-series.** *(Java engine change ⇒ rebuild + restart.)*

**N-series — data & networking (JSON + external requests)**
