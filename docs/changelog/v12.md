# v12

**2026-10-01** · since [v11](v11.md) · [download](https://github.com/irongete/brodgar-io-client/releases/tag/v12)

The fight in progress and the combat schools, readable and usable by addons.

## Client

### Terrain and view distance

- **Fixed** a far cell whose map data was still loading being taken as failed instead of asked again.

## Addon API

API edition **1.4** (was 1.2): an addon using the fight in progress declares `"api_version": "1.3"`, one using the combat schools `"1.4"`.

### Fight in progress

- **Added** [`session:fight():opponent()`](../addons/api/fight.md#an-opponent), every opponent of the fight, with `:current()` the target, and each one's initiative and give state.
- **Added** [openings](../addons/api/fight.md#an-opening), the icons beside you and each opponent, as `Opening` objects from `session:fight():opening()` and `opponent:opening()`.
- **Added** [`session:fight():action()`](../addons/api/fight.md#a-combat-action), the ten-key combat row, with `:cooldown()` and each side's `:last()` manoeuvre.
- **Added** [writes](../addons/api/fight.md#write-protected): `action:use()` (`fight.use`), `opponent():set()` to switch target (`fight.set`), `:pursue()` (`fight.pursue`) and `:give()` (`fight.give`).
- **Added** [the fight events](../addons/api/event/bus/fight.md): `Opponent*`, `Opening*`, `ManeuverUsed` and `CombatActionChanged`.
- **Changed** ⚠️ a fight's openings no longer fire `BuffAdded`, `BuffChanged` and `BuffRemoved`: listen to `OpeningAdded`, `OpeningChanged` and `OpeningRemoved`.
- **Removed** ⚠️ `session:fight():target()`: use `session:fight():opponent():current()`.

### Combat schools

- **Added** [`session:fight():school()`](../addons/api/fight.md#schools), the saved schools, with `:current()` the loaded one, and `school:load()` and `school:save()` under `fight.load` and `fight.save`.
- **Changed** ⚠️ [`deck()`](../addons/api/fight.md#a-deck-card) lists every hotkey place, empty or not, and takes `:get(n)`; `card:index()` is the hotkey number, and `card:exists()` is now `card:empty()`.
- **Changed** ⚠️ [counts](../addons/api/fight.md#a-manoeuvre) are renamed: `maneuver:dealable()` → `:max()`, `maneuver:used()` and `card:used()` → `:copies()`, `summary:used()` → `:spent()`.
- **Removed** ⚠️ `summary:activeSave()`, `:saveCount()` and `:deckSize()`: use `school():current()`, `school():count()` and `deck():count()`.
