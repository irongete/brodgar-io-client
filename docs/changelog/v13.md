# v13

**2026-10-03** · since [v12](v12.md) · [download](https://github.com/irongete/brodgar-io-client/releases/tag/v13)

The whole HUD can be rearranged by addons, the combat display included.

## Client

### Interface

- **Fixed** the belt jumping back above the chat every frame after an addon moved it: it stays where it was put.
- **Fixed** the chat landing its own height off the place an addon gave it, and losing that place while hidden.
- **Fixed** a window as large as the screen losing its place when the game window is resized.

## Addon API

API edition **1.5** (was 1.4): an addon using regions, the order of widgets, `widget:addon()` or `hafen.ui():root()` declares `"api_version": "1.5"`.

### UI

- **Added** [regions](../addons/api/ui/regions.md): widgets standing for what the client paints by hand, so an addon moves or hides the combat display's eight elements and the HUD's command line, last message and hidden chat lines.
- **Added** [`widget:raise()`, `widget:lower()` and `widget:z(n)`](../addons/api/ui/native.md#front-and-back-unprotected): a widget in front of or behind its siblings, within a band from `-9` to `9`.
- **Added** [`widget:addon()`](../addons/api/ui/widget.md#read-methods) and `:info().addon`, the addon that built a widget.
- **Added** [`hafen.ui():root()`](../addons/api/ui/custom.md#your-windows-live-in-the-layer), the top of the addon layer, to walk every addon's surfaces.
- **Changed** [`widget:position(x, y)`](../addons/api/ui/native.md#moving-and-resizing-unprotected) on the belt holds it, and on the chat places its top-left whether it is shown or hidden.
- **Changed** [`widget:value(row)`](../addons/api/ui/edit.md#driving-one-protected) on a list scrolls the picked row into view.
