# v17

**2026-10-20** · since v15 · [download](https://github.com/irongete/brodgar-io-client/releases/tag/v17)

Addons can read the state the game sends with its overlays, such as the strength of the cave-in warning dust, and the map window remembers its own size and place for each view.

## Client

### Windows

- **Improved** the compact and the extended map each keep the size and position you last gave them, and switching between the two puts each one back.

## Addon API

### World

- **Added** [`overlay:sdt()`](../addons/api/overlay.md#the-games-state-bytes), the state bytes the game sent with each of its overlays under one key, also in `overlay:info().sdt`.
- **Added** [`GobOverlaySdtChanged`](../addons/api/event/bus/world.md#an-overlays-state-changing), a world bus event with `:gob()`, `:key()` and `:sdt()`, fired when those bytes change or a second overlay of the resource arrives.
- **Changed** [the world](../addons/api/world.md#objects) no longer lists or announces the gobs the client makes for itself to carry a footstep's sound or a passing effect: no negative ids, no `GobAdded`.
- **Changed** ⚠️ [`overlay:key()`, `:gob()`, `:native()`, `:res()`, `:kind()`, `:count()`, `:exists()` and `:info()`](../addons/api/overlay.md#the-overlay-object) raise on an argument they do not take; drop the argument.
- **Fixed** [`event:gob()`](../addons/api/event/bus/world.md#overlays-coming-and-going) on `GobOverlayAdded`, `GobOverlayRemoved` and `GobSdtChanged`, which answered a gob that read as gone.

## Upstream

- Merged the upstream client of 2026-10-18, which makes its native Windows toolkit the default.
